# MoA# 🤟 모아(MoA) : OTT PIP 수어 통역 공생 서비스 대시보드

기존 OTT 플랫폼과 오버레이 연결을 통해 농인 시청자의 시청 접근권을 보장하는 맞춤형 AI 수어 통역 솔루션 '모아(MoA)'의 관리자 대시보드 프로토타입입니다.

## 📌 서비스 개요
* **서비스명:** 모아 (MoA)
* **핵심 타겟:** 수어를 제1언어로 사용하는 농인 시청자 (핵심 타겟 약 9만 명)
* **주요 특징:** 
  * 기존 OTT 플랫폼의 시스템을 파괴하지 않는 **비파괴형 연결 권리 계약**
  * 수어 통역사 채용의 한계를 극복한 **AI 3D 수어 아바타 자동 생성**
  * 버튼 1회 클릭으로 원본 영상 위에 수어 영상을 띄우는 **PIP 오버레이**

## ⚙️ 4단계 서비스 구동 파이프라인
1. **Step 1:** OTT 플랫폼과 연결 권리 계약
2. **Step 2:** 영상 판권 수령
3. **Step 3:** AI 기반 수어 영상 학습 및 사전 제작 (품질 검수)
4. **Step 4:** 모아(MoA) 앱 업로드 및 시청자 재생 연동

## 📊 관리자 대시보드 주요 기능 (본 페이지)
본 레포지토리는 모아 서비스의 원활한 파이프라인 구동과 비즈니스 모델을 관리하기 위한 웹 대시보드입니다.
* **통합 지표 관리:** 월 3,990원 구독 모델 및 광고 수익, 누적 가입자 트래킹
* **콘텐츠 상태 모니터링:** 작품별(예: 하이쿠키) AI 렌더링 상태 및 판권 계약 현황 확인
* **시청 환경 제어:** PIP 화면의 투명도 및 싱크(딜레이) 초기 설정값 관리

## 🛠 기술 스택
* HTML5, CSS3 (Tailwind CSS)
* Chart.js (통계 데이터 시각화)
